# ADR-001: Simulation core in C# (.NET), headless library

- **Alternatives considered:** Rust core with Godot bindings; C++
- **Reason and evidence:** Owner choice; one language with the Godot client; simpler AI-assisted development; data-oriented C# controls garbage collection. Reopen only if browser delivery becomes a requirement
- **Status:** Owner-confirmed (language), doctrine review Delegated
