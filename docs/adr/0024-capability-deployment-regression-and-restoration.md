# ADR-024: Capability, deployment, regression and restoration

Group in the original registry: Additions, 24 Nov 2026 (knowledge and historiography amendment, section 59). See [README.md](README.md) for the group note.

Capability states and transitions (K50) consume real production resources; regression when dependencies decay; codified knowledge can survive capability loss; restoration uses surviving knowledge, expertise and infrastructure (K51). Candidate mathematics: hazards with time-to-event sampling (ADR-012). Status: requirement owner-confirmed; formulation proposed.
