# ADR-020: Knowledge–Capability Separation

Group in the original registry: Additions, 24 Nov 2026 (knowledge and historiography amendment, section 59). See [README.md](README.md) for the group note.

Ownership, custody, access, acquisition, comprehension, absorption, operational capability and deployment are distinct states (K43, K44, K48, K50); a technology is never a Boolean unlock. Alternatives: classic tech tree unlocks. Consequences: K1 amended; capability per actor, region, institution and industry; tacit, codified, embodied, institutional, distributed, operational and dormant forms (K49); discipline-specific absorptive capacity. Status: owner-confirmed; state representation proposed for Pass 2.
