# ADR-032: Extension compatibility

Group in the original registry: Additions, 24 Nov 2026 (knowledge and historiography amendment, section 59). See [README.md](README.md) for the group note.

No modding support, no plugin or extension API and no mod tools; only the source code is published. Everything the amendments ask for (campaign histories, renderers, readers, export) is built in-house as capability expansions. Every published work and edition records the ruleset version and build identifier. Alternatives: plugin API; modded-campaign support. Reason: owner decision; mods are not needed to deliver the requested capabilities. Status: owner-confirmed 24 Nov 2026.
